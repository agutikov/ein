# Q-M1f.434 — A standard library rule is drawn canonical, else folded, else as Ein

A rule of the standard library is drawn on its family's page in the canonical form where that drawing is within the
bound on nodes the pages keep; else folded, where the folded drawing is within it, the image's text saying that it is
folded; else the rule is shown as Ein alone. The bound is fixed, and a rule past it is shown as Ein, not drawn larger.

**Why.** A drawing past the bound is too many nodes to read at a page's width, and a rule's Ein is its exact
statement. The fold takes a pattern's relation out of the drawing, which keeps drawn a rule that only its relations'
nodes made too large: a closing rule, whose patterns are each of two arrows, among them.

**Held by.** The pages of [the standard library's reference](../../ein/user/04-reference/04-stdlib/README.md#how-a-rule-is-shown),
whose rule regions and drawings are generated from the modules and the engine
([Q-M1f.375](Q-M1f.375-the-standard-librarys-reference-shows-usage.md)).
