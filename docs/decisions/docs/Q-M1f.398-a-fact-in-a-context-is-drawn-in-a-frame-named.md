# Q-M1f.398 — A fact in a context is drawn in a frame named for the context's relation

In a drawing of the graph, the ones the pages write by hand, a fact has one mark for each of the two things that
may be true of it ([Q-M1f.394](../language/Q-M1f.394-a-fact-is-in-the-global-context-in-a-facts.md)). An octagon is
**filled** exactly when the fact is held, in the global context. It stands **inside a dashed, rounded frame**
exactly when an argument arrow of a fact points at it, which is when it is in a context.

A frame is labelled with the relation of the facts that point at what is in it and the word *ctx*: *think ctx*. A
fact that facts of two relations point at is in one frame that names both, *says, think ctx*, since every object is
drawn once. Frames stand side by side and never one inside another; which fact speaks about a framed fact is read
off the arrows that enter the frame. An atom is in no frame. A pattern is drawn alike: a fact pattern under an
arrow of another is in a frame. A drawing with no fact under an arrow has no frame.

**Why.** *Held* and *in a context* are independent, so each has a mark of its own and the three cases are told
apart at a glance. A frame for each context fact, holding what that one fact speaks about, cannot be drawn where a
fact is in two contexts without drawing it twice. A frame around the held facts would change every drawing and
cannot stand beside another frame that overlaps it.

the context of a fact, which states the convention and draws the three cases;
[the rules](../../ein/reasoning/01-static-ir/02-rewriting-rules.md), § Packing and unpacking;
[facts](../../ein/user/03-syntax-and-semantics/03-facts.md) and
[rules](../../ein/user/03-syntax-and-semantics/05-rules.md), one drawing each.
