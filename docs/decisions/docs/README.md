# Decisions: the documentation

What a page, a comment or a decision of the project may state and cite, and how a claim about Ein is warranted. The
format and how a decision is cited: [`docs/decisions/README.md`](../README.md).

- [Q-M1e.1](Q-M1e.1-a-behaviour-is-refuted-by-a-banked-probe.md) — A behaviour is refuted by a banked probe, an absence by naming its check, a risk by nothing
- [Q-M1e.2](Q-M1e.2-an-argument-is-enough-only-when-its-premise-is.md) — An argument is enough only when its premise is enforced
- [Q-M1e.4](Q-M1e.4-an-exact-number-in-a-page-carries-the-command.md) — An exact number in a page carries the command or the test that checks it
- [Q-M1f.69](Q-M1f.69-a-guide-block-that-writes-an-ellipsis-is.md) — A guide block that writes an ellipsis is an excerpt, and its whole forms load together
- [Q-M1f.341](Q-M1f.341-the-project-documents-only-its-current-state.md) — The project documents only its current state
- [Q-M1f.342](Q-M1f.342-a-decision-is-a-question-with-its-final-answer.md) — A decision is a question with its final answer, kept under its id
- [Q-M1f.343](Q-M1f.343-a-page-or-a-comment-cites-a-decision-by-its-id.md) — A page or a comment cites a decision by its id, never a plan or a date
- [Q-M1f.344](Q-M1f.344-each-decision-is-one-file-in-a-folder-by-subject.md) — Each decision is one file, in a folder by subject
- [Q-M1f.345](Q-M1f.345-nothing-in-the-project-reads-links-or-names.md) — Nothing in the project reads, links or names the work that produces it
- [Q-M1f.346](Q-M1f.346-the-decisions-are-about-ein-not-about-how.md) — The decisions are about Ein, not about how the work on it is done
- [Q-M1f.347](Q-M1f.347-no-open-question-is-cited-by-the-project.md) — No open question is cited by the project
- [Q-M1f.348](Q-M1f.348-a-generated-file-says-it-is-generated-and-names.md) — A generated file says it is generated and names no tool
- [Q-M1f.349](Q-M1f.349-a-page-of-the-project-states-no-measurement.md) — A page of the project states no measurement
