# Q-M1f.349 — A page of the project states no measurement

A page of the project, a comment or a manifest note states no measured number: no time, no memory, no cost taken on
some machine on some day. A measurement is taken by the work on Ein and kept beside what takes it
([Q-M1f.345](Q-M1f.345-nothing-in-the-project-reads-links-or-names.md)). What a page may state is a number the
project itself checks: a size beside the command that re-takes it, or a count beside the test that pins it
([Q-M1e.4](Q-M1e.4-an-exact-number-in-a-page-carries-the-command.md)). Where a page needs to say that one thing
costs more than another, it says so as a relation a test holds, a proportion or a bound, and names the test.

**Why.** A measurement is true of one engine on one machine at one moment, and its warrant is when and where it was
taken, which the project does not record ([Q-M1f.341](Q-M1f.341-the-project-documents-only-its-current-state.md)).
A relation between costs, held by a test, stays true on every machine the test runs on.

**Held by.** `ein-infer/tests/arith_batch.rs`, which holds the calculator's cost as a proportion of a batch's size
rather than as a time; [Q-M1e.4](Q-M1e.4-an-exact-number-in-a-page-carries-the-command.md), which says what a number
in a page carries.
