# Q-M1f.347 — No open question is cited by the project

A question with no answer is work, and lives with the work
([Q-M1f.345](Q-M1f.345-nothing-in-the-project-reads-links-or-names.md)). Where the project cites a question, the
question has an answer: what Ein does today and, where part of it is postponed, why, or what it waits for. That
answer is a decision like any other ([Q-M1f.342](Q-M1f.342-a-decision-is-a-question-with-its-final-answer.md)), even
when what it says is that something is not done.

**Why.** A citation of an open question is a citation of the work, which is gone when the work is finished. And a
gap the project lives with is a fact about the project, which its reader needs stated as one: what Ein does in the
case, and why it does no more.

**Held by.** [`docs/decisions/README.md`](../README.md); the decisions that state a postponement, each a file under
`docs/decisions/` like any other, cited by its id: a loader message about a top-level form names no position
([Q-M1a.6](../diagnostics/Q-M1a.6-a-loader-message-about-a-top-level-form-names-no.md)), and a failed artefact write
keeps the run's exit code ([Q-M1e.22](../cli/Q-M1e.22-a-failed-artefact-write-keeps-the-runs-exit-code.md)).
