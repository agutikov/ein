# Q-M1f.473 — A program a page draws and no file holds is drawn from the page's text

Where a page shows the engine's drawing of a program that no file of the corpus holds, the drawing is the command's
output for the program as the page states it: its forms, as written in the page's text, and nothing more.

**Why.** The page's text is the program the reader has, and a file kept for one drawing would be a second copy of
it, which the page could drift from.

**Held by.** The pages that state such a program beside its drawing
([Q-M1f.467](Q-M1f.467-a-commands-drawing-on-a-page-is-its-output.md)).
