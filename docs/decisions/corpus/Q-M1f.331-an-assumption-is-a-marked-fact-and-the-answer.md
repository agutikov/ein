# Q-M1f.331 — An assumption is a marked fact, and the answer says it rests on it

An assumption a word problem makes, a quantity the problem does not state taken as some number, is a marked fact,
`(assumed QUANTITY NUMBER)`, written by hand or derived by a module the problem adopts. An answer computed from it
carries a fact beside it, `(rests-on QUESTION QUANTITY NUMBER)`: *the answer rests on the assumption that this
quantity is this number*. No search is involved.

**Why.** The answer and what it depends on are read off one state, and a reader sees which numbers the problem gave
and which were supposed. A supposition as a hypothesis would name itself in the state's commitment, but a gap and a
hypothesis together leave a stale fact in one state, so the marked fact is the form the examples are written in.

**Held by.** `examples/word_problems/gap_assume.ein` and `kinds_assume.ein`, assumptions written by hand, and
`kinds_listed.ein`, one derived by `listed_is_all.ein`, each with a claim on its `rests-on` fact.
