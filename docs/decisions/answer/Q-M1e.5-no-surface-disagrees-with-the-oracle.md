# Q-M1e.5 — No surface disagrees with the oracle, experimental or not

No surface of Ein, whatever it is called, states what the oracle contradicts or answers otherwise than another
command asked the same question. A surface that cannot yet say something true declines to say it; *experimental*
licenses a surface to be absent or to change, never to print evidence it does not have.

**Why.** An answer that is right only on the surfaces called stable is not an answer anyone can read without
knowing which surface printed it. One definition of R, held by one reference, is what lets every route, mode and
view be trusted alike.

**Held by.** `ein oracle`, R by brute force, the reference; `ein-infer/tests/explore.rs`: `every_mode_is_the_oracle`
and `every_order_of_the_tree_is_the_oracle`; `ein-infer/tests/claim_routes.rs`:
`every_claim_is_decided_as_the_oracle_decides_it`.
