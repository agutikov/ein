# Q-M1f.311 — Describe takes the tree and the classes, and the state route on request

On a monotone program, describe and `--count` have two routes, chosen by `--describe-route`. **`tree`**, the
default: R's states by the obligation tree, where root owes an instance a licence lets the tree branch on, and each
state's class by dualise and advance; it gives R, `k_c` and the minimal line exactly, and computes neither N nor an
empty R's owing frontier, which the read-out says, with the members met and the option. **`states`**: every alive
state once, N and the frontier among them; it is taken wherever the tree would only repeat it. A describe a
budget stops says, in its `note:`, the route's forecast, what was established and what was not, and the options.
`ein test` asks the state route for a region claim over the owing frontier. The option changes no part of R.

**Why.** Where root owes, the tree reaches R through far fewer saturations than visiting every alive state; the
state route still pays where N or the frontier is wanted, so each is there to be asked for.
