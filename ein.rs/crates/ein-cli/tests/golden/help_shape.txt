COMMAND ein solve
  ABOUT solve a puzzle: print the solution(s) or the unsat core
  OPTION --diff-models -- metavar=FILE arity=1 default=None choices=- group=- required=False help=after the answer, compare its models with the ones FILE lists ('closes R …', then 'model' and one fact per line) and print what matches, what is missing, what is spurious and what is one fact off. Changes stdout and nothing recorded
  OPTION --dump-answer -- metavar=DIR arity=1 default=None choices=- group=- required=False help=write the answer as files to DIR: the program, root, one loadable file per model and open state with the commitment that reached it, every refuted commitment, and answer.json (= --json-summary). DIR is made before the search; past that, stdout, stderr and the exit code are unchanged.
  OPTION --dump-config -c metavar=- arity=0 default=False choices=- group=- required=False help=print the resolved SolverConfig before solving
  OPTION --dump-lattice -- metavar=DIR arity=1 default=None choices=- group=- required=False help=persist every commitment the search tested, with its firings and outcome, to DIR (enterings/, proof_summary.json — docs/kernel/inference/lattice_dump.md). One dumper per solve, so not with --dump-states, -v, --layer-progress or -t
  OPTION --dump-region -- metavar=DIR arity=1 default=None choices=- group=- required=False help=write the solution region to DIR: every subset of the root candidates saturated by the program's rules alone, with no search machinery (region.json, region.md), and this run's walk over the lattice (walk.json) — docs/kernel/inference/region_dump.md. Runs after the solve; stdout, the exit code and the other artefacts are unchanged.
  OPTION --dump-states -D metavar=DIR arity=1 default=None choices=- group=- required=False help=persist the engine dump tree (root snapshot per layer + timeline) to DIR
  OPTION --events -- metavar=FILE.jsonl arity=1 default=None choices=- group=- required=False help=record the engine's step-by-step event log to FILE (one JSON object per line). Off by default and additive: stdout, stderr and the exit code are unchanged. Schema: docs/kernel/inference/events.md.
  OPTION --events-level -- metavar=EVENTS_LEVEL arity=1 default='normal' choices=normal|verbose group=- required=False help=(--events) `verbose` adds redundant firings and pre-candidate hypothesis skips — ~6x the volume.
  OPTION --exhaustive -e metavar=- arity=0 default=False choices=- group=stop required=False help=do not stop at the first model. Certification also needs the lattice to end within --max-set-size, which `exhausted` in --stats reports (slower)
  OPTION --full-kb-snapshots -F metavar=- arity=0 default=False choices=- group=- required=False help=(--trace) append a whole-KB snapshot of the final state
  OPTION --hyp-stats -H metavar=- arity=0 default=False choices=- group=- required=False help=print the root-hypothesis preview (total + per-relation breakdown + hypgen filter report)
  OPTION --jobs -j metavar=JOBS arity=1 default='1' choices=- group=- required=False help=threads for a layer's enterings, or 'auto' (default: 1). Same verdict, same models, same counters
  OPTION --json-summary -- metavar=FILE.json arity=1 default=None choices=- group=- required=False help=write the structured run summary (verdict, model, every engine counter, the root-saturation shape, the resolved config) to FILE as JSON. Additive: stdout, stderr and the exit code are unchanged.
  OPTION --lattice-order -o metavar=LATTICE_ORDER arity=1 default=None choices=lex|score-sum group=- required=False help=within-layer candidate ordering (S1.5b.26): 'lex' (canonical-tuple sort, the deterministic default) or 'score-sum' (S1.5a.7 hypgen scoring summed per set)
  OPTION --lattice-sanity-check -y metavar=- arity=0 default=False choices=- group=- required=False help=S1.5b.27 regression: for every alive size-k≥2 commitment, verify every (k-1)-subset parent path saturates to the same kb (1 + k + one per alive parent, so up to 2k+1 each; adds compile/enqueue/fire/quiesce events to --events)
  OPTION --layer-progress -- metavar=- arity=0 default=False choices=- group=- required=False help=stream the per-layer census to stderr and nothing per entering: three lines a layer — alive, then what the join proposed and the clauses filtered, then what entering them killed, learned and found
  OPTION --max-enterings -E metavar=MAX_ENTERINGS arity=1 default=None choices=- group=- required=False help=abort after N commitment tries
  OPTION --max-set-size -m metavar=MAX_SET_SIZE arity=1 default='5' choices=- group=- required=False help=commitment-set depth cap (default: 5)
  OPTION --max-time -T metavar=MAX_TIME arity=1 default=None choices=- group=- required=False help=abort after N wall-clock seconds
  OPTION --models -- metavar=FORM arity=1 default='list' choices=list|key|grid group=- required=False help=how to print the models: 'list' (a block per model, the default); 'key' (the smallest set of slots that tells them apart, and the table of combinations that occur — an ambiguous verdict only); 'grid' (each model and open state as a table, the anchor type's objects down the side, where the program's declarations license one). Changes stdout and nothing recorded
  OPTION --no-diagrams -G metavar=- arity=0 default=False choices=- group=- required=False help=(--trace) suppress all inline dot blocks
  OPTION --no-kill-cache -K metavar=- arity=0 default=False choices=- group=- required=False help=disable the lookahead-kill (not h) cache (pairs with --no-lookahead to exercise the raw loop)
  OPTION --no-lookahead -L metavar=- arity=0 default=False choices=- group=- required=False help=disable hypgen's one-step lookahead (forces deaths through the no-good learning path)
  OPTION --print-final-hfacts -f metavar=- arity=0 default=False choices=- group=- required=False help=dump only the hypothesis-target (query :hrules) facts per solution
  OPTION --print-final-positive -P metavar=- arity=0 default=False choices=- group=- required=False help=like --print-final-state but drops the (not …) facts
  OPTION --print-final-state -p metavar=- arity=0 default=False choices=- group=- required=False help=dump each solution's derived facts (for an unsat verdict, the unsat-core facts instead)
  OPTION --progress-every -g metavar=PROGRESS_EVERY arity=1 default='100' choices=- group=- required=False help=under --verbose, log every N-th entering (default 100; set 1 to log every entering)
  OPTION --region-limit -- metavar=N arity=1 default='16' choices=- group=- required=False help=(--dump-region) the most root candidates the region is computed for: 2^N saturations. Above it the directory holds the walk and a note says why; 17-19 warns, 20 and more warns with the projected cost.

  OPTION --reorder -R metavar=- arity=0 default=False choices=- group=- required=False help=(--trace) cluster steps by target entity instead of engine order

  OPTION --shuffle -z metavar=- arity=0 default=False choices=- group=- required=False help=shuffle the within-layer commitment order (a per-layer random permutation).   OPTION --solutions -n metavar=N arity=1 default='1' choices=- group=stop required=False help=stop after N distinct solutions (default: 1)
  OPTION --stats -s metavar=- arity=0 default=False choices=- group=- required=False help=print engine counters (k, enterings, layers, wall)
  OPTION --timing -t metavar=- arity=0 default=False choices=- group=- required=False help=print a per-phase wall-clock table: parse, kb load, compile, root saturation, hypothesis search (enterings, layers, saturations, per-hypothesis avg), and totals
  OPTION --trace -r metavar=FILE.md arity=1 default=None choices=- group=- required=False help=write the self-contained markdown derivation trace to FILE (a file, not stdout)
  OPTION --verbose -v metavar=- arity=0 default=False choices=- group=- required=False help=stream per-layer + per-entering progress to stderr
