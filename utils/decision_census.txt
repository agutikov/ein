# The hand half of `utils/decision_census.py`: one row an id.
#
#   key | class | subject | flags | note
#
# key      the census key: the id, or `Qn@LEDGER` where two ledgers number alike,
#          or `PHASE#n` / `STAGE#Qn` for a local number
# class    decision | open | not-carried; empty keeps the class read off the
#          ledger's state. A row with a class is counted as classed by hand.
# subject  the proposed folder under `docs/decisions/` (the script's SUBJECTS);
#          every decision has one
# flags    pending  answered, about work no plan has built yet: stays with its plan
#          verify   the answer as written may not describe today's engine
#          conflict the answer conflicts with a ruling that has no id
#          home     open, in a ledger under `docs/history/`: needs a home in `plans/`
# note     why, for a hand class; `-> ID` names the id that carries the decision
