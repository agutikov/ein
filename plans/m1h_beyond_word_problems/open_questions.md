## Q-M1h.1 — Where M1h sits against M1g

[M1g](../m1g_logic/README.md) *runs after M1f is complete*; nothing says whether this milestone runs before
it, after it or beside it. P1h.1 and P1h.2 need nothing of M1g; P1h.3 reads M1g's
[P1g.7](../m1g_logic/p1g.7_unsatisfiable_against_owing/README.md) (open against false) if that has been
ruled; M1g's own README was written when *"no M1h need"* answered a different proposal, an engine milestone.
The same question is
[Q-M1g.15](../m1g_logic/open_questions.md#q-m1g15--where-m1h-sits-against-this-milestone), asked once.

What the stage files add, as fact and not as an answer: each stage that reads something of M1g says which
stage of M1g builds it and what it does if that has not run
([README § Stage, phase, milestone](README.md#stage-phase-milestone)). So no stage of M1h is blocked by
M1g; three are poorer without it: [S1h.3.1](p1h.3_gaps_assumptions_and_readings/s1h.3.1_the_three_forms_of_a_gap.md)
(P1g.7's ruling), [S1h.1.2](p1h.1_temporal_and_causal_theories/s1h.1.2_an_event_as_an_instruction_or_a_relation.md)
(P1g.9's three methods) and S1h.4.2 (P1g.10's expressions, Q-M1h.2). No default is taken.

## Q-M1h.4 — The text, and its language

The user is bilingual and the repo's documents are in English; a text *"everybody would remember from
school"* depends on whose school. S1h.10.1 proposes a short list and stops; the choice is the user's.

One fact bears on it, taken on the release binary on 2026-11-13: **a `:source` string holds any Unicode, and a
name is ASCII.** A fact written `(went Vanya forest :source "Ваня пошёл в лес.")` loads, answers, and is
written back with its sentence by `ein saturate --dump` and by a `--dump-answer` state file (a scratch program
of four forms, `ein solve FILE --dump-answer DIR`). So a text in Russian can stand beside its facts sentence by
sentence, with the names of its people and things transliterated; the questions' `:goal-text` likewise.

## Q-M1h.11 — What *used* means

Added 2026-11-13, from the README's *further questions the phase meets*. A fact with two justifications has two
slices, and a query with several classes has an answer in each.

- **(a)** the slice of *this* derivation: the first justification of each fact, as a core is taken today. It
  may vary with rule order (a core is an explanation, the user's ruling of 2026-11-08).
- **(b)** the union over every recorded justification: everything some derivation of the answer used.
- **(c)** the intersection: what every derivation used, *required* in the strict sense.

And, across them: of one answer (one class in one state), or of a query's every class. S1h.2.4 computes all
three on programs that have a fact with two justifications and shows how far they differ. **Recommended, to be
confirmed by those numbers:** print (a) and say that it is one explanation; state (b) and (c) where they
differ from it.
