# P1f.8 — split and moved to M1g on 2026-11-13

**This phase is no longer here.** It was *Middle-school algebra and geometry*, planned 2026-11-11 as a phase of
[M1f](../README.md) and extended 2026-11-12. On 2026-11-13 the user split it into two phases and moved both to
[M1g](../../m1g_logic/README.md):

> plans/m1f_hypothesis_and_documentation/p1f.8_school_algebra_and_geometry seems too complex having both algebra
> and geometry, let's split it into 2 phases and move into m1g;
> plans/m1f_hypothesis_and_documentation/p1f.8_school_algebra_and_geometry/s1f.8.7_theorems_as_rules.md  probably
> will require new features in the engine

- **[P1g.10, school algebra](../../m1g_logic/p1g.10_school_algebra/README.md):** expressions, simplification,
  equations, a program that states false facts, compound numbers.
- **[P1g.11, school geometry](../../m1g_logic/p1g.11_school_geometry/README.md):** a figure as facts, theorems
  as rules, constructions, the diagram gap, and the report.

Nothing of the content was redesigned, and the files were moved with `git mv`
([P1g.10 § The move](../../m1g_logic/p1g.10_school_algebra/README.md#the-move-of-2026-11-13) has the record and
the choices the split forced). This page stays because pages that hold the user's replies as typed, and are
never edited, link to it and name the phase as *P1f.8*
([`questions.md`](../p1f.6_calculator/questions.md),
[`questions_round2.md`](../p1f.6_calculator/questions_round2.md)). M1f's phase number 8 is used and vacated; it
is not reassigned.
