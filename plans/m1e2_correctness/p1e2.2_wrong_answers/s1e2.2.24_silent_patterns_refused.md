#### Every shape, in a rule, an hrule and an obligation

`gen_shapes.py`'s 165 probes, release and debug alike (165 of 165 identical,
`shapes-before.json` against `shapes-before-debug.json`). Each family is

and in an obligation's:

- **Every argument kind in a guard** (61 probes, `g-*`), `(eq ?x A)` and
  `(neq ?x A)` beside `(p ?x)` over `(p a) (p b) (p 1) (p (f a))`:
  - a bound variable, a name, a string, an integer: the guard compares the
    values, the controls;
  - `1..3`: refused at load since S1e2.2.20;
  - **`_`: reads nothing**. It is a raw IR node (`compile.rs`' `guard_arg`,
    `GuardArgKind::Node`), equal to no value and to another `_`: `(eq ?x _)`
    never holds, `(neq ?x _)` always does, `(eq _ _)` holds. Under an
    `absent` the polarity flips: the `absent` always holds. W24's first shape;
  - **a form, `(f a)`, `(f ?y)` or `(f _)`: reads nothing**, by the same
    mechanism: `(eq ?x (f a))` never holds, even where `?x` is bound to the
    fact `(f a)`; `(eq (f a) (f a))` holds and `(eq (f ?y) (f ?z))` does not;
  - **a variable no premise before the guard binds: reads nothing**. A guard
    is judged where it is written, and an unbound variable compares as a
    null, equal only to another unbound one: `(eq ?x ?u)` never holds,
    `(neq ?x ?u)` always does, `(eq ?u ?v)` holds; and `(and (eq ?x a) (p
    ?x))` never fires, while `(and (neq ?x a) (p ?x))` fires for every `?x`,
    `a` included (`g-order-rule`);
  - **a keyword pair, `(eq ?x :k a)`: reads nothing** (a raw node);
    `(neq ?x :k a)` is a parse error, `NeqForm` being shape-pinned.
- **Every premise that is not a form** (64 probes, `p-*`): an atom, a
  variable, `_`, an integer, a string, as the whole `:match`, beside a
  premise in an `(and …)`, as a top-level `(or …)`'s disjunct, as an
  `absent`'s body, inside an `absent`'s conjunction, as a `forall`'s body and

    arguments), and as a `forall`'s body a macro arity error.
- **Every place a pattern inside a pattern takes** (30 probes, `n-*`),
