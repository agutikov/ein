## The case

[`examples/ein-bugs/wrong-answers/forced-2.ein`](../../../examples/ein-bugs/wrong-answers/forced-2.ein), seven lines:

```
(relation thing T) (relation q T) (relation bad T)
(thing one)
(rule taint () :match (q ?x)   :assert (bad ?x) :priority 200)
(rule kill  () :match (bad ?x) :assert (false)  :priority 300)
(query :goal (thing ?x) :no-hypothesis (bad))
```

```
$ ein solve -e -s -p examples/ein-bugs/wrong-answers/forced-2.ein          # default flags
  solutions (k)   0
  verdict         No solution — the constraints are contradictory
  unsat core (0 facts)
  exhausted        true
  enterings        0
```

The program without any hypothesis is consistent, so the right answer is
`Solution k = 1`, model ∅. The engine never entered a commitment, refuted the
program, certified the refutation, and named no fact it rests on.

**Mechanism** (`solve.rs:2427-2478` at `71dd237`, `promote_forced_positives`).
While `alive` is a singleton `{h}`, the cascade writes `h` **into root** with a
premise-less `<forced-positive>` provenance and re-saturates. If root is now
contradictory it returns `term = true`, and both callers (`solve.rs:1368-1377`
in phase 1, `1828-1836` between layers) call `root_dead`. Promotion is only
sound when `root ∪ {h}` is consistent. When it is not, the conclusion is
`¬h`, and root is the solution.
[`architecture_and_algorithms.md`](../../../docs/kernel/inference/architecture_and_algorithms.md)
calls the cascade *unit propagation*. There is no clause that **requires**
`h`, so it is not unit propagation. It is a guess written as a fact.

**Reach:** five corpus entries use the cascade, and **none** changes verdict
with it off ([inventory § 4](../inventory.md#4-reach--corpus-sweeps-run-for-this-inventory)).
The between-layers call site has no witness yet (inventory § 6).

## Two fixes, and which one

| | what | cost |
|---|---|---|
| **(a) promote only what is consistent** | a singleton whose promotion contradicts root is written as `¬h` (a death, with its core), not as `h` | keeps the cascade's speed where it is sound; one saturation per promotion, which it already pays |
| **(b) delete the cascade** | the corpus measurement says it decides no verdict | simplest. The question is what it buys in cost, which nobody has measured since it was named |

Measure (b)'s cost on the corpus first. If it is noise, (b) is the honest
answer, because a heuristic that changes no answer and can change one wrongly
is a liability. Otherwise take (a).
