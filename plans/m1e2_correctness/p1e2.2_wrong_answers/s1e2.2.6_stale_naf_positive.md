## The case

`(p one)` is derived at root by a rule guarded by `(absent (q one))`. The
search then commits `(q one)`. The guard is now false, nothing retracts
`(p one)`, and the recorded state contains both.

```
$ ein solve -e -s -P examples/features/07_unstratifiable.ein      # default flags
  solutions (k)   1       Solution       exhausted true
  (p one)
  (q one)
```

That fixture's own header says `{p, q}` *"is not a model of this program
under any reading"*, and the engine prints exactly that state as the model. No
`warn` fires of either category. The narrower probe
[`examples/ein-bugs/wrong-answers/stale-naf-fork.ein`](../../../examples/ein-bugs/wrong-answers/stale-naf-fork.ein)
(`p ← thing ∧ absent q`; `p ∧ q → ⊥`) shows the cost. The model `{q}` is
unreachable, because the stale `p` kills it. With `-L` the forced-positive
cascade (W2) then turns it into a false `Contradiction`.

**Why it is contested.** Under Q-M1e.6 read literally, with an append-only KB
and *saturated* meaning *quiescent*, `{(p one),(q one)}` is a saturated
consistent state, and it qualifies. Under the reading the fixture's header
takes, a model must satisfy every rule **including the guard that derived its
facts**, and it does not. The review chooses.

## Readings, and the fix each implies

| reading | right answer | fix |
|---|---|---|
| **guards are premises** (the fixture's header) | `07_unstratifiable` has no stable model, so `Contradiction`, or a refusal (below); `stale-naf-fork` answers `{(q one)}` | at record: any fact whose derivation reads `(absent X)` where `X` now holds is **stale**, and the state either re-derives without it or is not a model. That is a bounded check over provenance the engine keeps |
| **refuse what cannot be stratified** | a load error | the static non-stratifiability diagnostic `01_grammar.md` has called future work since S1.7.4, which M1f's [S1f.5.6](../../m1f_hypothesis_and_documentation/p1f.5_documentation_and_other/s1f.5.6_rule_priority.md) plans to build from the rule dependency graph. That is a dependency on M1f, or the diagnostic moves here |
| **append-only is the semantics** | today's answers | not wrong. The fixture's header and `absent_semantics.md` say so plainly, and the case closes `not-wrong` |

The first two compose. Refuse the unstratifiable program, and check staleness
at record for a stratified program whose search commits a guarded relation
(`stale-naf-fork` is stratified).
