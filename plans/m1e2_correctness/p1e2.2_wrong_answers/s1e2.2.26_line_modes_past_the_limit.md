## The case

Past `--region-limit`, on a program the static check flags, describe (`ein
solve FILE`) certifies the members it met with no member of R met below them,
`{∅}` when ∅ is in R, and says the maximal line is not known; `ein solve FILE
--minimal` and `--maximal` label every member they met as on their line. At
`94c75204`, release and debug alike (2026-11-05):

| program (candidates) | describe's minimal line | `--minimal` labels minimal | `--maximal` labels maximal |
|---|---:|---:|---:|
| `examples/saturation/square-unique/corner-house.ein` (118) | 1, ∅ | 65 214 | 65 214, ∅ among them |
| `examples/features/01_not_and_absent.ein` (35) | 1, ∅ | 64 655 | 64 655 |
| `examples/features/04_open.ein` (81) | 1, ∅ | 64 761 | 64 761 |
| `examples/saturation/square-unique/cul-de-sac.ein` (114) | 1, ∅ | 64 817 | 64 817 |
| `examples/saturation/square-unique/terminus.ein` (153) | 1, ∅ | 64 514 | 64 514 |
| `examples/lattice/06_friends_tables.ein` (19) | 1 | 21 | 21 |
| `examples/lattice/10_fifo_gap.ein --region-limit 1` (2) | 1, ∅ | 2: ∅, `{(a one)}` | 2: ∅, `{(a one)}` |

On the last, `ein oracle` gives minimal `{∅}` and maximal `{(a one), (b
one)}`, so each line mode labels a state the oracle puts on no such line. The
read-out says *minimal line 65 214 states (a lower bound: the run stopped
first)*, which is no lower bound (the minimal line is one state), and the
summary writes `lines: ["minimal"]` for a state describe's summary writes
`lines: []` for.

**The mechanism.** `explore::flagged`: past the limit a question that is not
answered in layer order (`(Which::All | Which::Minimal, Ask::Find | Ask::Single)`)
asks `cube_in_order` with `Which::All` and `Ask::Find(u64::MAX)`, and the
comment says its members are *printed as members and not as line members*;
but `Space::answer(opts.mode, …)` then labels them with the mode's line, and
`read_out.rs`'s line row counts them as the line. Describe takes
`partial_cube`, which certifies a member with no member of R below it, since
every subset was met first. Nothing holds it: `ein-infer/tests/explore.rs`
holds every mode to the oracle within its limit, and no corpus entry declares
a line mode on these programs. The approved interface
([`solve_interface.md` § 3.3](../p1e2.1a_the_solution_region/solve_interface.md#33-a-program-the-static-check-flags))
says such states are printed as members, not as line members.

## The ruling

[Q-M1e2.19](../open_questions.md#q-m1e219--what-do---minimal-and---maximal-answer-past-the-limit),
2026-11-05, as recommended:

1. This stage files it as a register row, **W27**, and fixes it before the
   close, after S1e2.2.25 and before P1e2.3's S1e2.3.8–.10.
2. **The fix matches describe.** Past `--region-limit` on a program the
   static check flags, `--minimal` certifies exactly what describe certifies,
   a met member with no member of R met below it (`{∅}` when ∅ is in R),
   counts the other members met and leaves them to `--dump-answer`; `--maximal`
   certifies none and says the maximal line is not known, as describe does.

## The method

1. **Re-take and list first, before any edit.** Every mode (describe,
   `--minimal`, `--maximal`, `--single`, `-n N`, each line mode with `-n N`,
   `--count`) on every program past a limit, in release and debug:
   - the flagged programs past the default limit (the table above);
   - every flagged corpus program and register witness under
     `--region-limit k` for each k below its candidate count, where the
     oracle's R is known, every state a mode labels held to the oracle's
     line;
   - **the monotone routes stopped by `--region-budget`** (the state route
     and route 1; the six `square-*` cubes, `syntax/arg-kinds` and the
     `zebra2-minus-15` pair stop at the default budget): does a line mode
     there label only what it certifies, and does it agree with describe?
   - `--single` and `-n N` past the limit: each printed state a member of R,
     no word stronger than the run can certify.

   Record every disagreement with describe or the oracle, beyond the one
   found. One the ruling does not cover is a stop, with a recommended
   default.
2. **Bank the smallest witness** and file **W27** `open`: its `now` the line
   mode's answer, its `right` describe's certified line (and, for
   `--maximal`, none, the line not known). A witness at default settings
   needs a flagged program past 16 candidates; write the smallest one that
   shows it, beside the corpus programs above, and `lattice/10 --region-limit
   1` as the lever's row if the register wants it (its `settings`).
3. **Prototype the fix** and sweep every declared run of the corpus, the
   register's witnesses and the step-1 probes, at HEAD and under the
   prototype, and run `cargo test --workspace` under it, before any edit.
   Every move listed and explained.
4. **Tests**, each failing at HEAD in dev and release: every line mode past
   the limit certifies what describe certifies (the same states, the same
   lines in the summary, the line row's count), and under a lowered
   `--region-limit` every state a mode labels on a line is on the oracle's
   line. `explore.rs` holds the modes to the oracle within the limit; this
   holds them past it.
5. **The pages**: [`read_out.md`](../p1e2.1a_the_solution_region/read_out.md)'s
   partial-run paragraphs, among them *"all 64 761 members
   `features/04_open.ein` meets are minimal"*, which is false at HEAD
   (describe certifies one, ∅); `solve_interface.md` § 3.3's row for
   `--minimal`, `--maximal` and describe; `solution_semantics.md`'s
   paragraph on a flagged program past the limit; and any golden page
   (`read_out_examples.md`) that shows a line mode past the limit.

## Acceptance

- Past `--region-limit` on a program the static check flags, `--minimal`
  lists exactly describe's certified minimal line, counts the other members
  met and names `--dump-answer` for them; `--maximal` lists no state and says
  the maximal line is not known; the summary's `lines` and the read-out's line
  row say the same; release and debug alike.
- Under a lowered `--region-limit`, no mode labels a state on a line the
  oracle does not put it on, on every flagged corpus program and register
  witness.
- W27's rows `fixed`; no answer moves outside the line modes past a limit,
  and every move listed before the edit.
