# S1e2.2.13 — W12: an exhausted `Contradiction` reports a 0-fact core

**Phase:** [P1e2.2](README.md) (The wrong answers)
**Estimate:** 1 day
**Depends on:** the review (**contested**), [S1e2.2.2](s1e2.2.2_forced_positive_refutes.md)
(one witness is W2's, and may simply stop existing).
**Carries:** M1e S1e.3.1's § *what it did not do*, which recorded this as
*"honest"*.

## The case

```
$ ein solve -e -s examples/ein-bugs/alive-empty-phase1.ein
  solutions (k)   0
  verdict         No solution — the constraints are contradictory
  unsat core (0 facts)
  exhausted        true
```

The **verdict** is right under ruling A (CO-M1's fix). The **core** is
empty. The refutation's premises are kill-cache negatives with provenance
`<lookahead-dies-immediately>`, and the forced-positive cascade's writes are
`<forced-positive>` (W2's witness, [`examples/ein-bugs/wrong-answers/forced-2.ein`](../../../examples/ein-bugs/wrong-answers/forced-2.ein)).
Both are **premise-less** engine writes, so the frontier walk stops at them and
returns ∅. An unsat core is *a set of program facts whose conjunction with the
rules is inconsistent*. The empty set with this program's rules is
consistent, so ∅ is not a core of this program.

**Why it is contested.** S1e.3.1 read *0 facts* as honest: the engine does
not know which facts, and says so by naming none. The case for *wrong* is that
the engine **does** know. A kill-cache negative `¬h` is written because
`root ∪ {h}` died, and that death has a core of its own.

## The fix

Give the two engine writes their premises. `¬h` from the kill cache rests on
the dead singleton's core, minus `h`. A forced positive (if S1e2.2.2 keeps the
cascade) rests on the deaths of its siblings. The frontier walk then reaches
program facts, and `explain.rs`'s minimisation applies unchanged. Where a
premise genuinely cannot be recovered, the read-out says *core not available*
rather than printing `0 facts`, since a count of zero reads as a claim.

## What moves

The two witnesses' cores; the `<lookahead-dies-immediately>` row in
[`reserved_engine_strings.md`](../../../docs/kernel/inference/reserved_engine_strings.md);
any corpus `Contradiction` whose core today passes through a kill-cache
negative. Measure that number first, because it is the size of the change.
