## Why

[N5](README.md#candidates-found-on-the-way), found 2026-11-04 while S1e2.2.16
was filed. The printer drops what tells two values apart:

- `ein saturate --dump examples/syntax/arg-kinds.ein` prints `(r 7 "a
  string")` as `(r 7 a string)` and `(r _ ?x)` as `(r ?x)` (at `5fd72d03`).
- `ein solve --dump-answer DIR`, whose states are each to be loadable,
  writes a state's facts the same way, and re-loading `DIR/models/01.ein`
  gives a different state: `(holds "x y")` is written `(holds x y)`
  (`build/s1e2.2.7/textkey/str-space.ein`).
- The int `1` and the symbol a string `"1"` names print alike, so the
  read-out cannot tell apart two facts the KB holds apart. S1e2.2.16's
  `answer_dump` test names the files that print alike as exceptions to its
  fixpoint check.

No answer moves; the printed form is wrong.

## The method

1. **Re-take first**, at the stage's HEAD, and find every place a fact or a
   value is printed (the read-out, `--dump`, `-f`/`-p`/`-P`, `--dump-answer`'s
   files, `ein render kb`, the DOT labels, the event stream's fact strings,
   the case pages' reader). List every golden the fix moves before editing.
   A golden that moves and is not on the list is a finding.
2. **One printer.** A value prints as text the loader reads back to the same
   value: a symbol that would not lex back as itself as an atom (a space, a
   parenthesis, a quote, all digits, a leading `?`, `:` or `_`, a range's
   shape) prints as a quoted string; an int prints bare. If the KB holds a
   value no text can denote (step 1 finds what `(r _ ?x)` in a fact loads
   as), the stage stops and reports what it holds, with a recommended default.
3. **The claim as a test.** For every corpus program and every state
   `--dump-answer` writes, loading `models/NN.ein` gives that state's facts
   by value. S1e2.2.16's exceptions in `answer_dump` go.
4. **The pages:** `inference/answer_dump.md` (each state loadable, now held),
   `read_out.md` where it shows a value, this phase's README (N5 fixed, the
   re-take's row).

## Acceptance

- Every state `--dump-answer` writes reloads to its own facts, by value, on
  every corpus program, held by a test with no exceptions.
- The int `1` and the symbol `1` print differently on every surface.
- No answer, exit code or register row moves.
