### What § The region shows

Every case page has a **§ 5 The region**, between *the models* (§ 4) and
*where it went wrong* (now § 6). Every program page (`--corpus`, the
gallery) has the same section in place of the bare drawing. It holds:

1. **The drawing with this run on it**: `ein oracle --dump`'s cube, and the
   row's `[case.now]` drawn from its own `--dump-lattice` and
   `--dump-answer` (`ein render region CUBE --visited … --answer …`), with
   the lines view beside it.
2. **What the drawing found**, quoted from `ein render region --view
   table`'s head: *missing*, *spurious*, *not reached* (a stopped run), *≠
   the cube*, and how many nodes the run visited. Every node named there
   links to its row, on the layer page that holds its `<a id="mMASK">`.
3. **R, three ways**: the oracle's route, monotonicity, k_s · k_c, empty,
   both lines and holes, beside the register's `[case.region]` (route 1 or
   2, with *the same* / *differs* against the oracle) and the run's.
4. **The answer, three ways**: the part of R the run asked, by the oracle;
   the register's `right` (the walk's vocabulary, models over `closes`, said
   so); and the run's states, each linked to its state file. An owing empty
   R adds its frontier.

Past the oracle's limit (five rows: W1/zebra2-hints, W1/branching-07,
W1/branching-04-L, W10/alt-cap-core, C1/branching-06) the section is one

### The overlay, under ruling (a)

`ein render region` lost the walk (`walk.json`, `WalkDoc`, `Skip`) and
reads a region run instead. What changed in what it says:

- **Shape** is what the run did: octagon, a state it reported (or a node of
  an empty R's owing frontier); box, a node it visited; ellipse, neither,
  with *above a dead node*, *the run stopped first* or *not needed* under
  the facts.
- **The comparison is with the part of R the run asked**, by state. A bare
  `ein solve` asks all of R, so any node of R no reported state holds is
  MISSING, whichever line it is on; `--maximal` and `--minimal` ask one line.
  On a run that stopped (`-n`, `--single`, a budget) the same node is *not
  reached*, orange, a bound and not a defect (C3). A reported state outside
  the part asked is SPURIOUS, with why (dead or owing in the cube, or in R
  and off the line asked). The legend's *lines compared: both — which line
  is the answer is S1e2.1a.3's ruling (a)* is gone.
- **Every reading the run printed is checked against the cube**: a visited
  node's kind and closure, a state's lines (C1 one way, and C2 the other on
  a line the run certified), a frontier node's debt. And the exclusion check
  carries over as licence L1's: an unvisited node above a dead node the run
  visited is *unsound* when the cube says it is alive, with the `✗ alive`
  edge. A correct engine never trips either, so the tests write a wrong
  answer into a copy of the run's dump.
- The table gives every node an anchor and links its lists to the rows; the
  walk's column (*the walk stood on 1 nodes*, `walk: root`) is a *run*
  column, present only when a run is drawn.

**The four overlay tests are back**, in `region_render.rs`, against a region
run: W1 (the walk's answer written into the run's `index.json` leaves `{(p
A)}` MISSING; `--maximal` and a bare `solve` miss nothing), W3 (naf-nowb's

### Decisions taken without a ruling

Each can be overruled here.

1. **A line run is compared with its line, not with all of R.** The Note
   above has *a node of R that no recorded state holds is missing, whichever
   line it is on*, which is exact for the walk (it claimed to answer *the
   solutions*) and for a bare `ein solve` (it describes R). A `--maximal` run
   asks the maximal line, so a non-maximal node of R is not its omission:
   the drawing shows it in R, and names nothing.
2. **`--answer` beside `--visited`.** The approved interface had
   `--visited` alone; it cannot say what the run reported.
3. **W13 is not one of the twelve**, and neither are W1's six rows S1e2.1a.10
   filed after the W1 reading. Both are listed for the user after the twelve,
   since none of them carries a `[case.review]`.
