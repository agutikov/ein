## Context

The verdict block prints `solutions (k)` and one block per recorded node.
`--json-summary` carries `verdict.k`, `solutions`, `open_states` and
`exhausted`. None of them names a line of R, so a reader cannot tell whether
`k = 2` counts minimal or maximal nodes. Once R is the answer, a number
that does not say which line it counts is a new instance of the defect this
milestone is about.

## Acceptance

- **Every surface says which line it reports**, as ruled in (a): the verdict
  block, `--json-summary`, `--dump-answer` (`models/` per line, or one line
  named in `index.json`), `--models list|key|grid`, `--trace`'s headline and
  `ein test`'s report. Where (a) rules *both*, both are reported with their
  counts.
- **Empty R is split**: no alive node is `Contradiction`, and alive nodes that
  all owe is `Open`. The wording is the 2026-08-25 ruling's, restated.
- **Holes**, as ruled in (d): reported, qualified or refused, and never
  silent.
- **`exhausted`** certifies what (g) says it certifies, and the read-out
  sentence says so.
- **The search is not fixed here.** The surfaces report what the walk found,
  in R's vocabulary. A register row whose wrong answer changes *shape* but not
  *content* is re-recorded in the same commit, and none flips to `fixed`.
- **Every golden that moves is named first**: the corpus summaries, the trace
  goldens, `read_out.rs`'s cells, `help_shape.txt` if an option changes, and
  `corpus_shapes.md5`. An unexplained move is a stop.
