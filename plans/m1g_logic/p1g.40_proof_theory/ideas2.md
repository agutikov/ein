Ниже — терминология, используемая в **Mathematical Logic, Proof Theory, Model Theory, Automated Theorem Proving и Formal Verification**.

Принципиально важно различать свойства **формул**, **доказательств**, **теорий**, **моделей**, **систем вывода** и **алгоритмов поиска**. Например, *true*, *valid*, *provable*, *sound* и *satisfiable* — не синонимы.

Обозначения:

- $$\varphi,\psi$$ — формулы; $$\Gamma,T$$ — множества формул (предпосылки, аксиомы теории).
- $$M$$ — модель; $$P$$ — proof system; $$A$$ — алгоритм поиска доказательств.
- $$\bot$$ — противоречие (falsum); $$\top$$ — истина (verum).
- $$\vdash_P$$ — синтаксическая выводимость в $$P$$; $$\models$$ — семантическое удовлетворение или следование.

## **1. Truth, Satisfaction, Validity — истинность и семантика**

| English / Русский                            | Обозначение                                                           | Объяснение                                                                                                                                          | Где применяется            |
| -------------------------------------------- | --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------- |
| **True / Истинно**                           | $$M\models\varphi$$                                                 | Формула истинна при заданной интерпретации (и оценке свободных переменных, если они есть).                                                          | Model Theory, Semantics    |
| **False / Ложно**                            | $$M\not\models\varphi$$                                             | Формула ложна в модели $$M$$. В классической логике эквивалентно $$M\models\neg\varphi$$.                                                       | Model Theory               |
| **Satisfied / Удовлетворено**                | $$M\models\varphi$$                                                 | Модель удовлетворяет формуле. Для открытых формул также требуется назначение переменных.                                                            | Model Theory, SMT          |
| **Holds / Выполняется, имеет место**         | $$M\models\varphi$$                                                 | Утверждение выполняется в модели или структуре. *Holds* — обычный глагол, не отдельный логический статус.                                           | Mathematics, Model Theory  |
| **Valid / Общезначимо**                      | $$\models\varphi$$                                                  | Истинно во всех моделях выбранной логики.                                                                                                           | Logic, Model Theory        |
| **Invalid / Необщезначимо**                  | $$\not\models\varphi$$                                              | Существует контрмодель, в которой формула ложна.                                                                                                    | Logic                      |
| **Satisfiable / Выполнимо**                  | $$\exists M:M\models\varphi$$                                       | Существует хотя бы одна модель формулы.                                                                                                             | SAT, SMT, Model Theory     |
| **Unsatisfiable / Невыполнимо**              | $$\nexists M:M\models\varphi$$                                      | Не существует модели, удовлетворяющей формуле.                                                                                                      | SAT, SMT, ATP              |
| **Falsifiable / Опровержимо интерпретацией** | $$\exists M:M\not\models\varphi$$                                   | Существует контрмодель. В классической логике эквивалентно невыполнимости $$\neg\varphi$$ **не является**; напротив, $$\neg\varphi$$ выполнима. | Logic, Semantics           |
| **Contingent / Контингентно**                | $$\operatorname{Sat}(\varphi)\land\operatorname{Sat}(\neg\varphi)$$ | Формула истинна в одних моделях и ложна в других.                                                                                                   | Propositional, Modal Logic |
| **Tautology / Тавтология**                   | $$\models\_{\mathrm{PL}}\varphi$$                                   | Истинна при всех оценках пропозициональных переменных.                                                                                              | Propositional Logic        |
| **Contradiction / Противоречие**             | $$\models\neg\varphi$$                                              | Формула ложна при всех интерпретациях; невыполнима.                                                                                                 | Logic, SAT                 |
| **Countermodel / Контрмодель**               | $$M\models T,\ M\not\models\varphi$$                                | Модель предпосылок, в которой заключение ложно.                                                                                                     | Model Theory, ATP          |
| **Model / Модель**                           | $$M\models T$$                                                      | Структура, удовлетворяющая всем аксиомам $$T$$.                                                                                                   | Model Theory               |

**Важное различие:**

$$ \underbrace{M\models\varphi}\_{\text{true in a model}} \qquad \underbrace{\models\varphi}\_{\text{valid in all models}} $$

Формула может быть истинной в конкретной модели, но не быть общезначимой.

## **2. Entailment, Derivability, Provability — следование и выводимость**

| English / Русский                                  | Обозначение                                      | Объяснение                                                                                                                                                | Где применяется         |
| -------------------------------------------------- | ------------------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| **Entailed / Семантически следует**                | $$T\models\varphi$$                            | Формула истинна во всех моделях $$T$$.                                                                                                                  | Model Theory            |
| **Semantic Consequence / Семантическое следствие** | $$\varphi\in\operatorname{Cn}\_{\models}(T)$$  | Формула принадлежит множеству семантических следствий теории.                                                                                             | Logic                   |
| **Derivable / Выводимо**                           | $$T\vdash_P\varphi$$                           | Существует формальный вывод из $$T$$ по правилам $$P$$.                                                                                               | Proof Theory            |
| **Provable / Доказуемо**                           | $$T\vdash_P\varphi$$                           | Существует доказательство формулы в системе. Обычно синоним *derivable*.                                                                                  | Proof Theory, ATP       |
| **Theorem / Теорема**                              | $$\vdash_P\varphi$$ или $$T\vdash_P\varphi$$ | Формула, доказанная без дополнительных предпосылок либо из аксиом $$T$$.                                                                                | Mathematics, Logic      |
| **Consequence / Следствие**                        | $$T\models\varphi$$ или $$T\vdash\varphi$$   | Может означать семантическое или синтаксическое следствие; необходимо уточнять.                                                                           | Logic                   |
| **Non-derivable / Невыводимо**                     | $$T\nvdash_P\varphi$$                          | Формального доказательства нет. Не означает, что $$\neg\varphi$$ доказуема.                                                                             | Proof Theory            |
| **Unprovable / Недоказуемо**                       | $$T\nvdash\varphi$$                            | Формула не имеет доказательства в данной теории.                                                                                                          | Proof Theory            |
| **Refutable / Опровержимо формально**              | $$T\vdash_P\neg\varphi$$                       | Доказуемо отрицание формулы.                                                                                                                              | Proof Theory            |
| **Refuted / Опровергнуто**                         | $$T\vdash\neg\varphi$$                         | Отрицание доказано. В refutation-based ATP может означать получение $$\bot$$ из $$T\cup\\{\varphi\\}$$.                                               | ATP, Logic              |
| **Disprovable / Формально опровержимо**            | $$T\vdash\neg\varphi$$                         | Возможно доказать отрицание утверждения.                                                                                                                  | Logic                   |
| **Independent / Независимо от теории**             | $$T\nvdash\varphi\land T\nvdash\neg\varphi$$   | Ни формула, ни её отрицание не доказуемы.                                                                                                                 | Mathematical Logic      |
| **Undecidable in T / Неразрешимо в теории**        | $$T\nvdash\varphi,\ T\nvdash\neg\varphi$$      | В этом смысле синоним независимости; не путать с алгоритмической неразрешимостью.                                                                         | Logic                   |
| **Admissible Rule / Допустимое правило**           | $$\frac{\Gamma_1\ \cdots\ \Gamma_n}{\Delta}$$  | Добавление правила не создаёт новых теорем (для правил без предпосылок контекста); более точно: доказуемость всех посылок влечёт доказуемость заключения. | Structural Proof Theory |
| **Derivable Rule / Выводимое правило**             | —                                                | Правило можно воспроизвести существующими правилами вывода, в том числе под произвольными предпосылками.                                                  | Proof Theory            |

Обрати внимание на четыре разных статуса:

$$ \begin{aligned} T\vdash\varphi& &&\text{provable}\\\ T\vdash\neg\varphi& &&\text{refutable}\\\ T\nvdash\varphi& &&\text{unprovable}\\\ T\nvdash\varphi\land T\nvdash\neg\varphi & &&\text{independent} \end{aligned} $$

Последнюю строку корректнее читать как два отдельных метаутверждения, а не как одну формулу с конъюнкцией.

## **3. Soundness, Completeness, Consistency — свойства систем и теорий**

| English / Русский                                           | Обозначение                                                | Объяснение                                                                                         | Где применяется           |
| ----------------------------------------------------------- | ---------------------------------------------------------- | -------------------------------------------------------------------------------------------------- | ------------------------- |
| **Sound / Корректна**                                       | $$T\vdash_P\varphi\Rightarrow T\models\varphi$$          | Система вывода не доказывает семантически неверных следствий.                                      | Proof Theory              |
| **Complete / Полна относительно семантики**                 | $$T\models\varphi\Rightarrow T\vdash_P\varphi$$          | Все семантические следствия формально выводимы.                                                    | Logic, Proof Theory       |
| **Consistent / Непротиворечива**                            | $$T\nvdash_P\bot$$                                       | В классической логике теория не доказывает противоречие.                                           | Logic                     |
| **Inconsistent / Противоречива**                            | $$T\vdash_P\bot$$                                        | Из аксиом выводится противоречие.                                                                  | Logic                     |
| **Syntactically Complete / Синтаксически полна**            | $$\forall\varphi:T\vdash\varphi\lor T\vdash\neg\varphi$$ | Для каждого предложения теория доказывает его или отрицание.                                       | Model Theory              |
| **Incomplete Theory / Неполная теория**                     | $$\exists\varphi:T\nvdash\varphi,\ T\nvdash\neg\varphi$$ | Существует независимое предложение.                                                                | Mathematical Logic        |
| **Decidable / Разрешима алгоритмически**                    | $$\operatorname{Thm}(T)$$ recursive                      | Существует завершающийся алгоритм определения доказуемости любого предложения.                     | Computability Theory      |
| **Undecidable / Неразрешима алгоритмически**                | $$\operatorname{Thm}(T)$$ nonrecursive                   | Такого алгоритма не существует.                                                                    | Computability, ATP        |
| **Semidecidable / Полуразрешима**                           | $$\operatorname{Thm}(T)$$ r.e.                           | Существует алгоритм, который находит доказательство, если оно есть, но может не завершиться иначе. | ATP                       |
| **Conservative Extension / Консервативное расширение**      | $$T'\supseteq T$$                                        | $$T'$$ не доказывает новых предложений на старом языке $$T$$.                                  | Proof Theory, Foundations |
| **Categorical / Категорична**                               | —                                                          | Все модели заданной мощности изоморфны; без уточнения мощности — все модели изоморфны.             | Model Theory              |
| **Model-Complete / Модельно полна**                         | —                                                          | Всякое вложение моделей теории является элементарным.                                              | Model Theory              |
| **Finitely Axiomatizable / Конечно аксиоматизируема**       | —                                                          | Теорию можно задать конечным набором аксиом.                                                       | Logic                     |
| **Recursively Axiomatizable / Рекурсивно аксиоматизируема** | —                                                          | Существует эффективное описание аксиом, обычно рекурсивно перечислимое.                            | Computability, Logic      |

**Два принципиально разных значения completeness:**

$$ \underbrace{T\models\varphi\Rightarrow T\vdash\varphi}\_{\text{semantic completeness of calculus}} $$

$$ \underbrace{T\vdash\varphi\ \text{or}\ T\vdash\neg\varphi}\_{\text{syntactic completeness of theory}} $$

Классическая логика первого порядка полна в первом смысле, а арифметика Пеано неполна во втором.

## **4. Proof Search, Saturation, Rewriting — алгоритмические свойства**

| English / Русский                                    | Обозначение                                                                             | Объяснение                                                                                       | Где применяется              |
| ---------------------------------------------------- | --------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ | ---------------------------- |
| **Terminates / Завершается**                         | $$A(x)\downarrow$$                                                                    | Алгоритм завершает работу на данном входе.                                                       | ATP, Computability           |
| **Non-terminating / Незавершающийся**                | $$A(x)\uparrow$$                                                                      | Вычисление не завершается.                                                                       | Computability                |
| **Strongly Normalizing / Сильно нормализующий**      | $$SN(\rightarrow)$$                                                                   | Не существует бесконечных цепочек преобразований.                                                | Term Rewriting, Proof Theory |
| **Weakly Normalizing / Слабо нормализующий**         | $$WN(\rightarrow)$$                                                                   | Из каждого состояния существует хотя бы один конечный путь к нормальной форме.                   | Rewriting                    |
| **Confluent / Конфлюэнтен**                          | $$b\leftarrow^\*a\rightarrow^\*c\Rightarrow\exists d:b\rightarrow^\*d\leftarrow^\*c$$ | Любые два расходящихся пути можно соединить.                                                     | Rewriting, Proof Search      |
| **Locally Confluent / Локально конфлюэнтен**         | $$b\leftarrow a\rightarrow c\Rightarrow\exists d:b\rightarrow^\*d\leftarrow^\*c$$     | Любое расхождение за один шаг можно соединить.                                                   | Rewriting                    |
| **Church–Rosser / Свойство Чёрча — Россера**         | $$\leftrightarrow^\*\subseteq\rightarrow^\*\circ\leftarrow^\*$$                       | Эквивалентные по преобразованиям объекты имеют общий редукт.                                     | Lambda Calculus, Rewriting   |
| **Fair / Справедливый поиск**                        | —                                                                                       | Постоянно применимые правила или задачи не игнорируются бесконечно.                              | Saturation, ATP              |
| **Refutationally Complete / Полон по опровержению**  | $$T\models\bot\Rightarrow T\vdash_P\bot$$                                             | Если предпосылки невыполнимы, система способна вывести противоречие.                             | Resolution, ATP              |
| **Search Complete / Полный поиск**                   | —                                                                                       | Стратегия находит доказательство при его существовании, при необходимых условиях справедливости. | ATP                          |
| **Redundant / Избыточный**                           | —                                                                                       | Факт, правило или шаг можно удалить без потери требуемых следствий.                              | Saturation, Rewriting        |
| **Irredundant / Неизбыточный**                       | —                                                                                       | Удаление элемента нарушает заданный критерий сохранения.                                         | Proof Minimization           |
| **Minimal / Минимальный**                            | —                                                                                       | Нет собственного подмножества с требуемым свойством.                                             | MUS, Proof Search            |
| **Minimum / Наименьший по размеру**                  | $$\arg\min \|S\|$$                                                                    | Имеет минимальную мощность среди всех решений.                                                   | Optimization                 |
| **Fixed Point / Неподвижная точка**                  | $$F(S)=S$$                                                                            | Применение оператора больше не изменяет состояние.                                               | Datalog, Saturation          |
| **Least Fixed Point / Наименьшая неподвижная точка** | $$\operatorname{lfp}(F)$$                                                             | Наименьшая по включению неподвижная точка.                                                       | Logic Programming            |
| **Monotone / Монотонный**                            | $$A\subseteq B\Rightarrow F(A)\subseteq F(B)$$                                        | Увеличение входа не уменьшает результат.                                                         | Fixed-Point Theory           |
| **Inflationary / Расширяющий**                       | $$A\subseteq F(A)$$                                                                   | Результат содержит исходное множество.                                                           | Saturation                   |
| **Idempotent / Идемпотентный**                       | $$F(F(A))=F(A)$$                                                                      | Повторное применение ничего не меняет.                                                           | Closure Operators            |

Особенно важно: **monotonicity, inflationarity, idempotence и confluence — четыре различных свойства**.

Оператор замыкания (*closure operator*) обычно определяется как монотонный, расширяющий и идемпотентный.

## **5. Refutation, Contradiction, Inconsistency — отрицательные результаты**

| English / Русский                                 | Обозначение                                                   | Объяснение                                                                             | Где применяется           |
| ------------------------------------------------- | ------------------------------------------------------------- | -------------------------------------------------------------------------------------- | ------------------------- |
| **Negation / Отрицание**                          | $$\neg\varphi$$                                             | Логическая операция отрицания.                                                         | Logic                     |
| **Falsum / Ложь, абсурд**                         | $$\bot$$                                                    | Константа ложности; в классической логике невыполнима.                                 | Proof Systems             |
| **Verum / Истина**                                | $$\top$$                                                    | Константа истинности.                                                                  | Logic                     |
| **Contradictory / Противоречащие**                | $$\varphi,\neg\varphi$$                                     | Пара формул, которые не могут быть одновременно истинны в классической модели.         | Logic                     |
| **Contradiction Derived / Выведено противоречие** | $$T\vdash\bot$$                                             | Получено формальное доказательство абсурда.                                            | ATP                       |
| **Refutation / Опровержение**                     | $$T,\neg\varphi\vdash\bot$$                                 | Доказательство $$\varphi$$ через противоречие с её отрицанием в классической логике. | Resolution, Tableau       |
| **Counterexample / Контрпример**                  | $$M\models T\land\neg\varphi$$                              | Объект или модель, опровергающая предполагаемое следствие.                             | Model Checking            |
| **Nogood / Запрещённая комбинация**               | $$C\subseteq H$$                                            | Набор гипотез, совместное принятие которых недопустимо.                                | ATMS, Constraint Learning |
| **Unsatisfiable Core / Невыполнимое ядро**        | $$C\subseteq T,\ C\models\bot$$                             | Подмножество предпосылок, уже являющееся невыполнимым.                                 | SAT, SMT                  |
| **MUS / Минимальное невыполнимое подмножество**   | $$C\models\bot,\ \forall C'\subsetneq C:C'\not\models\bot$$ | Минимально по включению невыполнимое ядро.                                             | SAT, Diagnosis            |
| **MCS / Минимальное корректирующее множество**    | —                                                             | Минимальный набор ограничений, удаление которого делает систему выполнимой.            | SAT, Diagnosis            |

Термин *refutation* имеет два распространённых контекста: опровержение конкретной формулы и вывод противоречия из множества предпосылок. В ATP второе особенно распространено.

## **7. Рекомендуемая терминология для Ein**

С учётом разделения saturation, hypothesis lattice и contradiction handling, я бы использовал следующие термины в API, документации и научных текстах:

| Термин          | Когда использовать                                                       |
| --------------- | ------------------------------------------------------------------------ |
| `derived`       | Факт получен применением правил                                          |
| `derivable`     | Факт может быть получен формальным выводом                               |
| `proven`        | Имеется завершённое доказательство                                       |
| `refuted`       | Доказано отрицание утверждения                                           |
| `contradiction` | Выведен $$\bot$$ или обнаружена формально определённая несовместимость |
| `inconsistent`  | Множество предпосылок допускает вывод противоречия                       |
| `satisfiable`   | Существует семантическая модель                                          |
| `unsatisfiable` | Семантической модели не существует                                       |
| `unknown`       | Система не установила ни доказательство, ни опровержение                 |
| `independent`   | Метатеоретически установлена недоказуемость обоих вариантов              |
| `saturated`     | Достигнуто замыкание относительно заданных правил                        |
| `closed`        | Состояние замкнуто относительно оператора вывода                         |
| `admissible`    | Правило допустимо относительно исчисления                                |
| `sound`         | Правила или алгоритм не порождают семантически некорректных результатов  |
| `complete`      | Система обладает точно определённой формой полноты                       |

Особенно рекомендую **не смешивать&#x20;**`false`**,&#x20;**`refuted`**,&#x20;**`inconsistent`**&#x20;и&#x20;**`unknown`.

Например, отсутствие доказательства:

$$ T\nvdash\varphi $$

не означает ни:

$$ T\vdash\neg\varphi $$

ни:

$$ T\models\neg\varphi $$

А `unknown` в работающем солвере означает лишь отсутствие установленного результата, а не математически доказанную независимость.

**Самое полезное концептуальное разделение для Ein:** `true/false` относятся к семантической интерпретации, `provable/refutable` — к отношению формального вывода, `consistent/inconsistent` — к множеству предпосылок, `sound/complete` — к системе вывода, а `confluent/terminating/fair` — к процессу преобразования или поиска.
