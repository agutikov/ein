# P2.2b — open questions: the phase's

The questions the phase raises for the user, for [the milestone's ledger](../../open_questions/README.md), kept as it
keeps its own: one file a question, `<topic>/<id>-<slug>.md`, its id the next free `Q-M2.<n>` of the milestone's one
sequence, which [the milestone's ledger](../../open_questions/README.md#questions-of-a-phase) names. The phase's
design questions, each with its default, are in [its README](../README.md#design-questions-each-with-its-default)
until a stage decides one or raises it here.

**At the phase's close** what is open moves to [the milestone's `open_questions/`](../../open_questions/README.md),
under the same topic; what is ruled goes with the phase's folder.
