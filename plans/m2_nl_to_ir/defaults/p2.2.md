## What a run commits

The slim records of S2.2.5 (its defaults 15 and 16) were taken under the ruling of 2026-11-26 on what a run
commits, which [the user's rule of the same day](../README.md#what-is-committed) replaced: what a script or a model
run writes again is not committed. What P2.2 committed before the rule stays tracked, and a new run writes under a
`runs/` or `out/` folder git ignores.
