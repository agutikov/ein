## Context

The contract's default 4 makes the answer query the one query that carries a `:goal-text`. The model, alone,
wrote a query a question; asked for one, it folds its questions into one `and`, with the grammar and without it
([L-M2.21](../findings/model/L-M2.21-the-model-s-zebra-answer-query-asks-one-person-both-questions.md)). In Ein a
query a question works as it stands: `examples/zebra3.1.ein` with its one query written as two, the same `?who` in
each, prints *Norwegian drinks water.* and *Japanese owns the zebra.* under `--single`. What stands in the way is
EinAf's own rule: the check reports `several-answer-queries`, and `einaf::answer` prints the first line alone.

And the reader scores a string: *The statements do not determine the answer.* is read right on `gap` while the
check holds `name-not-listed` on the very relation the query reads
([L-M2.22](../findings/model/L-M2.22-a-fixed-text-scored-right-can-rest-on-a-contradiction-of-the-model-s-own.md)).

## Acceptance

On Q-M2.35's ruling, **a query a question**:

- **The contract**: every query that carries a `:goal-text` is an answer query, one for each sentence of the text
  that ends in `?`, in the text's order ([04-contract](../../../docs/einaf/04-contract.md)).
- **The prompts**: the excerpt and the step-1 template say so; the `shops` example's query becomes two; and the
  excerpt gains the sentence it lacks whatever is ruled: *a variable written twice in one form is the same object
  in both places; two forms share no variable.*
- **Step 1's grammar**, rendered on the text, holds as many answer queries as the text has questions.
- **The answer** (`einaf::answer`): each answer query's line, in order, and the fixed text chosen a query, so that
  one question can be determined where another is not.
- **The check**: `several-answer-queries` goes; *fewer answer queries than questions* takes its place.
- **The steps by hand**: `einaf/contract/zebra/` takes the two queries; `examples/zebra3.1.ein` keeps its joint
  query, the test comparing the two files less the query.
- **Held by an invariance**, a test of EinAf's gate step: the Zebra steps by hand with the joint query and with a
  query a question print the same sentences under every question of `ein solve`.

Whatever is ruled, **the reader's two counts** (`einaf::answer::score`, or S2.5.3's reader if its first part has
run): *right*, and *right with no finding of the check on a relation the answer query reads*; for a contradiction,
right with a core that holds two statements of the text. On P2.2's records of the library condition the second
count is 0 of 13 word texts and 0 of 3 Zebra texts, which the test holds.
