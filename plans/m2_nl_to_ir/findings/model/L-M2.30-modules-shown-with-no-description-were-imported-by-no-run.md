## What

A directory of modules given beside the library is shown to the model *each by its forms, no comment of its file*:
its declarations, and each rule's name, parameters and `:why` (`einaf::catalogue::Given::text`). **Thirteen runs had
the word problems' own modules shown so, offered to the grammars and loadable, and no program imported one.** The
standard library, shown with a description and a worked program an entry, was selected on every text as its entries
spell it. The model's record on the two attribute puzzles follows how plainly a rule is described: `symmetric` right
where written; `converse` four written and four wrong; `compose` never; `top` and `meet` the example's shape with
the names changed.
