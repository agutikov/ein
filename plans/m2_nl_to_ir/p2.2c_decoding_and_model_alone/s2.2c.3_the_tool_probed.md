# S2.2c.3 — The tool, probed

**Phase:** [P2.2c](README.md) (A generation that ends, and the model alone)
**Status:** planned 2026-11-27; not started. **It has an item only where S2.2c.2 finds a text the model fails
alone on**; where it finds none, the stage records that and ends.
**Depends on:** [S2.2c.2](s2.2c.2_the_model_alone.md): the texts, and which of them the model fails alone on;
[S2.2.2](../p2.2_formalizer/s2.2.2_model_runtime.md): a function declared to the model, a turn on a kept context;
[S2.2.4](../p2.2_formalizer/s2.2.4_passes.md): the excerpt, the catalogue and the examples a prompt holds of Ein;

**Carries:** proposal 22 of [the analysis of P2.2](../p2.2_formalizer/report/ANALYSIS.md#104-further-steps): the
tool probed early, before the filter's loop is built.

## Context

The user's core idea has two halves: Ein as a filter of thoughts, and Ein as a tool the model may call. P2.2
built one shot of the first. The second is planned last in [P2.4](../p2.4_loop/README.md)
([S2.4.6](../p2.4_loop/s2.4.6_ein_as_a_tool.md)). A few episodes now, on texts where the model fails alone, say
whether the model calls Ein at all, what it writes with nothing holding the syntax, and whether the reply changes
its answer: enough to say which arrangement P2.4 builds first, and no more.

## Acceptance

- A function, `ein_solve`, one argument, a program; its description carries what the steps' prompt holds of Ein.
  Its result is what `ein solve` prints of the program through the bounded call, cut to a stated size; a parse
  error and a load's refusal are results too.
- A few episodes a text, thinking on, the model's own chain, seeded, a plan committed first: the texts S2.2c.2
  found the model fails alone on, and the two edits of the Zebra text, where a model that recalls believes the
  wrong thing.
- **Per episode**: whether it called and how often; each program it wrote (parse, load, the outcome among the
  seven, the check's findings); whether its answer after a reply differs from its answer before; whether its final
  answer is what its last run printed; whether it is right.
- The report says, for the user: whether the tool is where P2.4 starts, and what of
  [Q-M2.40](../open_questions/einaf/Q-M2.40-is-the-model-reasons-and-ein-checks-its-answer-an-arm.md) the episodes
  show.

## Tasks

### Task T2.2c.3.1 — The function and its reply

The description, written from the prompts' parts as they stand; the reply, with its cut. A call is the model's
native function call, as the host probe saw it written; a fenced block read as a call is the fallback if the
model cannot quote a program in an argument, recorded as P2.4's default 15 foresees.

### Task T2.2c.3.2 — The episodes

The plan, then the runs: a turn, the call, the reply on the kept context, to a stated number of calls or the
model's answer. Every program goes through `einaf::kernel`'s bounded call.

### Task T2.2c.3.3 — The report, and what the stage found

The stage's folder and its report: an episode quoted whole where the reply changed the answer and where it did
not. Of Ein, to [the evaluation](evaluation/README.md): what the kernel's reply, as `ein solve` prints it, gave
a model with nothing between them. Of the model, to [the findings](findings/README.md).
