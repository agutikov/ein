## Context

The check says what the tools read right; this stage asks whether the model, given it, writes step 1 right. On the
formalizer that stands when the stage runs, with its baseline taken the same day, so that no difference is the
formalizer's.

## Acceptance

- **The arms, on the six texts**, each a config of the steps' command, every run recorded:
  0. no analysis (the baseline);
  1. AMR as text;
  2. AMR as Ein facts;
  3. the best analysis beside AMR (a dependency parse, coreference, word senses), as text;
  4. **the model's own analysis first**: `qwen3.5:4b` writes the same markup under a grammar of it, then step 1
     reads it (the user's first question, *can the LLM do the analysis instead?*);
  5. **AMR read into step 1's facts by rules, with no model**: **a stage of its own since 2026-11-27**,
     [S2.2f.2a](s2.2f.2a_amr_to_step1_by_rules.md), on the user's word (*"make a separate stage for it, before
     S2.2f.3"*), which runs no model and so does not wait for S2.2c.1. Its programs, read on the same cells, stand
     beside this stage's arms. Where S2.2f.2a's table says the rules' program helps, it may also be given to the
     model as step 1's start: an arm of this stage then.
- Each run's step 1 read against the hand's step 1 on S2.2f.1's failure classes, cell by cell, and by the contract's
  check; whether it loads.
- Where an arm does better on the six, S2.2.4's sixteen texts under it.
- **The Zebra puzzle one shot** (`einaf from-text`) under the best arm: its program, its outcome and its answer,
  beside P2.2's.
- The plan of generations committed before the first generation; records under `runs/`, not committed.
