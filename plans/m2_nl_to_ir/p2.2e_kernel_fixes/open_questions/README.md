# P2.2e — open questions: the phase's

The questions the phase raises for the user, for [the milestone's ledger](../../open_questions/README.md), kept as it
keeps its own: one file a question, `<topic>/<id>-<slug>.md`, its id the next free `Q-M2.<n>` of the milestone's one
sequence, which [the milestone's ledger](../../open_questions/README.md#questions-of-a-phase) names. The defaults the
plan took are in [its README](../README.md#defaults-taken-at-the-plan); the questions it reads, raised before it,
are the milestone's. **An answer about Ein is a file under `docs/decisions/`**, under the id of its question,
written with the change that makes it true.

**At the phase's close** what is open moves to [the milestone's `open_questions/`](../../open_questions/README.md),
under the same topic; what is ruled stays in the phase's folder.
