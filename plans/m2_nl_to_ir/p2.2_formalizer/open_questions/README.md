# P2.2 — open questions: the phase's

The questions the phase raises for the user, for [the milestone's ledger](../../open_questions/README.md), kept as it
keeps its own: one file a question, `<topic>/<id>-<slug>.md`, its id the next free `Q-M2.<n>` of the milestone's one
sequence, which [the milestone's ledger](../../open_questions/README.md#questions-of-a-phase) names.

**At the phase's close** what is open moves to [the milestone's `open_questions/`](../../open_questions/README.md),
under the same topic; what is ruled stays in the phase's folder.

**The phase closed 2026-11-27, and all thirteen questions moved**: none was ruled in the phase, and each stands
with its default until the user rules. The index below is kept as the map; its links are the milestone's files.
Q-M2.35 to Q-M2.42, raised by [the analysis of the phase](../report/ANALYSIS.md) and the routing of its results, were
filed at the close, in the milestone's folder.
