# P2.2 — findings: the phase's

What the phase finds that is neither a finding of Ein ([its evaluation](../evaluation/README.md)) nor a question for
the user ([its open questions](../open_questions/README.md)): of EinAf, the plan, the process, the gate, the host. One
file a finding, `<topic>/L-M2.<n>-<slug>.md`, its id the next free of the milestone's one sequence, which
[the milestone's findings](../../findings/README.md) names.

**At the phase's close** what is open moves to [the milestone's `findings/`](../../findings/README.md), under the same
topic; what is closed stays in the phase's folder.

**The phase closed 2026-11-27.** The eight open findings moved to the milestone's folder (L-M2.7, L-M2.8, L-M2.10,
L-M2.16, L-M2.18, L-M2.19, L-M2.21 and L-M2.22), each with the stage that owns it since, and the eleven closed are
here. The index below is kept whole; a moved finding's link is the milestone's file. L-M2.24 to L-M2.30, which
[the analysis of the phase](../report/ANALYSIS.md) held and no ledger did, were filed at the close, in the
milestone's folder.
