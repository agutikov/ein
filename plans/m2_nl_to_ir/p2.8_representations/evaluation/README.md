# P2.8 — the evaluation of Ein: the phase's entries

one file an entry, `<topic>/E-<n>-<slug>.md`, under the milestone's topics, its id the next free of the milestone's one
sequence of `E-n`, which [the milestone's evaluation](../../evaluation/README.md) names.

**At the phase's close** what is open, and every strength, moves to
[the milestone's `evaluation/`](../../evaluation/README.md), under the same topic; what is closed goes with the
phase's folder.
